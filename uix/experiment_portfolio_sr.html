          Formulazione matematica
          Modello Sharpe ratio configurato
        

        

          
          

            
Problema originale

            

              Massimizzazione Sharpe ratio con vincoli long-only e budget unitario.
            


            

              
Obiettivo:

              

                \[\max_{\mathbf{x}} \quad \frac{\boldsymbol{\mu}^\top \mathbf{x}}{\sqrt{\mathbf{x}^\top \boldsymbol{\Sigma} \mathbf{x}}}\]
                max  μ'x / √(x'Σx)
              

            


            

              
Vincoli base:

              

                
                  \[\begin{aligned}
                  \sum_{i=1}^{n} x_i &= 1 && \text{(budget totale)} \\[4pt]
                  0 \leq x_i &\leq U && \forall i \text{ (bounds)}
                  \end{aligned}\]
                
                
                  Σᵢ xᵢ = 1  (budget totale)
                  0 ≤ xᵢ ≤ U  ∀i (bounds)
                
              

            


            

              
Cardinalità:

              

                \[\sum_{i=1}^{n} \delta_i \leq K, \quad x_i \leq U \cdot \delta_i, \quad \delta_i \in \{0,1\}\]
                Σᵢ δᵢ ≤ K,  xᵢ ≤ U·δᵢ,  δᵢ ∈ {0,1}
              

            


            

              
Vincoli settoriali:

              

                \[L_s \leq \sum_{i \in s} x_i \leq U_s \quad \forall s \in \mathcal{S}\]
                Lₛ ≤ Σᵢ∈ₛ xᵢ ≤ Uₛ  ∀s ∈ S
              

            


            

              
Valori configurati

              
    
                
  • n = 50 asset
    • 
                
  • U = 1.0 (peso massimo per asset)
    • 
                
  • K = — (max posizioni)
    • 
                
  • 
                  Vincoli settoriali: —
                
    • 
              

            

          


          
          

            
Problema trasformato

            

              Riformulazione convessa: minimizzazione varianza con rendimento normalizzato.
            


            

              
Obiettivo:

              

                \[\min_{\mathbf{x}_s, \kappa} \quad \mathbf{x}_s^\top \boldsymbol{\Sigma} \mathbf{x}_s\]
                min  xₛ'Σxₛ
              

            


            

              
Vincoli trasformati:

              

                
                  \[\begin{aligned}
                  \boldsymbol{\mu}^\top \mathbf{x}_s &= 1 && \text{(rendimento normalizzato)} \\[4pt]
                  \sum_{i=1}^{n} x_{s,i} &= \kappa && \text{(budget scalato)} \\[4pt]
                  0 \leq x_{s,i} &\leq U \cdot \kappa && \forall i \\[4pt]
                  \frac{1}{\mu_{\max}} \leq \kappa &\leq \frac{1}{\mu_{\min}} && \text{(bounds scala)}
                  \end{aligned}\]
                
                
                  μ'xₛ = 1  (rendimento normalizzato)
                  Σᵢ xₛᵢ = κ  (budget scalato)
                  0 ≤ xₛᵢ ≤ U·κ  ∀i
                  1/μₘₐₓ ≤ κ ≤ 1/μₘᵢₙ  (bounds scala)
                
              

            


            
            

              
Vincoli settoriali scalati:

              

                
                  \[\begin{aligned}
                  L_s \cdot \kappa &\leq \sum_{i \in s} x_{s,i} \leq U_s \cdot \kappa && \forall s \in \mathcal{S}
                  \end{aligned}\]
                
                
                  Lₛ·κ ≤ Σᵢ∈ₛ xₛᵢ ≤ Uₛ·κ  ∀s
                
              

              
Vincoli settoriali configurati.

            


            
            

              
Vincoli cardinalità (big-M):

              

                
                  \[\begin{aligned}
                  \sum_{i=1}^{n} \delta_i &\leq K \\[4pt]
                  x_{s,i} &\leq M_i \cdot \delta_i && \forall i \\[4pt]
                  M_i &= \frac{U_i}{\mu_{\min}}, \quad \delta_i \in \{0, 1\}
                  \end{aligned}\]
                
                
                  Σᵢ δᵢ ≤ K
                  xₛᵢ ≤ Mᵢ·δᵢ  ∀i
                  Mᵢ = Uᵢ/μₘᵢₙ,  δᵢ ∈ {0, 1}
                
              

              
I coefficienti big-M dipendono dal dataset caricato.

            


            

              Nota: senza cardinalità il problema è un QP convesso.
              Con cardinalità configurata diventa MIQP con variabili binarie δᵢ
              (anche se K = n).
            

          


          
          

            
Ricostruzione

            

              Recupero della soluzione originale dal problema trasformato.
            


            

              

                
                  \[x_i = \frac{x_{s,i}}{\kappa}, \quad SR = \frac{1}{\sqrt{obj^*}}\]
                
                xᵢ = xₛᵢ / κ,  SR = 1 / √(obj*)
              

            

          


          
          

            
Legenda

            

              

                
\(x_i\)xᵢ

                
Peso originale dell'asset i

              

              

                
\(x_{s,i}\)xₛᵢ

                
Peso scalato dell'asset i nel problema trasformato

              

              

                
\(\kappa\)κ

                
Variabile di scala: κ = 1/(μᵀx)

              

              

                
\(\delta_i\)δᵢ

                
Indicatore binario di selezione (solo con cardinalità)

              

              

                
\(\boldsymbol{\mu}\)μ

                
Vettore rendimenti attesi (tutti positivi dopo preprocessing)

              

              

                
\(\boldsymbol{\Sigma}\)Σ

                
Matrice di covarianza (semidefinita positiva)

              

            

            

              Nota: Il tasso risk-free è fisso a 0 nella versione corrente.
              I coefficienti big-M per i vincoli di cardinalità dipendono dal dataset.
